# 反馈报告模板

尖括号占位符替换为实际值；某节无内容则删除该节，不留空壳。

## 报告：`<YYYY-MM-DD>-<主题短语>.md`

~~~~markdown
# Skill 反馈报告：<目标 skill 名> · <主题短语>

## 元信息

| 项 | 值 |
|----|----|
| 目标技能 | `<skill 名>` |
| 安装路径 | `<实际安装位置，如 ~/.pi/agent/skills/<name>/、项目内 skills/<name>/>` |
| 来源 | `<上游仓库 URL / 本仓库自研 / 未知>` |
| 发现日期 | `<YYYY-MM-DD>` |
| 缺陷类型 | `<内容过时 / 步骤缺失 / 触发描述误导 / 脚本 bug / 兼容性>` |
| 验证状态 | 已验证可复现 |

## 任务场景

<在做什么任务、为何用到该 skill、期望什么结果，两三句。>

## 问题

### skill 原文指引

> 引用有欠缺的原文片段，标明所在文件路径。

### 实际表现

<报错信息或行为偏差，关键部分原样粘贴。>

## 已验证的替代方案

<步骤或代码，附实际执行过的命令与关键输出。>

## 修改建议

<改哪份文件的哪一段、怎么改。>

## 备注

<可选：影响范围、关联报告链接、环境差异。无则删本节。>
~~~~

## 索引：`index.md`

~~~~markdown
# Skill 反馈索引：<目标 skill 名>

| 日期 | 主题 | 缺陷类型 | 验证状态 | 状态 | 报告 |
|------|------|----------|----------|------|------|
| <YYYY-MM-DD> | <主题短语> | <缺陷类型> | 已验证 | 待处理 | [报告](<YYYY-MM-DD>-<主题短语>.md) |
~~~~

状态列写入时固定填 `待处理`，只有消费方才能改成 `已采纳` / `已废弃`。
