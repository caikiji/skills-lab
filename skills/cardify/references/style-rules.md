# 卡片格式与硬约束

阈值常量统一定义于 scripts/cardfmt.py，本文档仅作说明，冲突以代码为准。

## 文件格式

```markdown
# <主题>                      ← 可选首行

◆ 卡 1/M ｜ 总卡 · <标题>
一句话：<≤40 字，含锚点括号>
- <子卡标题>
关联：→ 卡2 ｜ → 卡3

◆ 卡 2/M ｜ <类型> · <标题>
一句话：<≤40 字，含锚点括号>
- <要点>（<锚点：代码实体或 文件:行号>）
代码块用 ``` 围合，≤15 行
关联：← 卡N ｜ → 卡M
```

## 硬约束清单（--check 逐条判定）

| 编号 | 规则 | 阈值 |
|------|------|------|
| C1 | 总张数 | 4~9（1 总卡 + 3~8 子卡） |
| C2 | 卡号连续 | 1..M 各恰好一次，卡头 /M 一致 |
| C3 | 第一张必须总卡 | 类型词为「总卡」 |
| C4 | 类型词合法 | 6 词表之一 |
| C5 | 标题 | 非空，≤12 字 |
| C6 | 一句话 | 非空，≤40 字，含锚点括号 |
| C7 | 要点 | 1~5 条；每条 ≤60 字、只一个句子、含锚点 |
| C8 | 总卡要点 | 必须与子卡标题一一对应（双向） |
| C9 | 关联卡号 | 在 1..M 内，不得指向自身 |
| C10 | 代码块 | ≤15 行 |
| C11 | 禁用词 | 标题/一句话/要点中不得出现词表词 |

## 禁用词表

本质、核心、赋能、闭环、范式、护城河、引擎、中枢、关键、深度、价值、智能、高效、强大、优雅、完美、无缝、打通

## 锚点

锚点 = 成对中文括号，内容两种：

1. 代码实体（函数/变量/类/常量/参数），如 `（Create）`、`（out_trade_no）`
2. 代码引用 `文件:行号` 或 `文件:起始~结束`，如 `（pay/service.go:45）`、`（pay/service.go:30~65）`

代码引用相对项目根解析（卡片文件位于 `<项目根>/.temp/cardify/`）。构建时自动读取对应行内联为代码块，HTML 里默认折叠、点击路径展开；--check 校验文件存在与行号有效。推荐能引用代码就用引用，代码由工具读取，避免 agent 抄错。

## 语气

像代码注释：动词开头，不加形容词修饰锚点，每条要点一个可回代码验证的事实断言。
