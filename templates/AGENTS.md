# 全局约定

## 环境
- 使用 bash，不使用 powershell / cmd。
- 使用 uv 管理 Python 包，不使用 pip。
- 需要当前时间时，使用 bash 命令 date。

## 语言
- 注释、Docstring、文档、提交信息必须用中文编写，专业术语（API、token 等）除外。
- 注释单条不超过 3 行；回答超过 50 行时先给结论再展开。

## 代码风格
- 函数签名、类属性、数据类字段必须带完整类型标注。
- 条件分支过多时，优先用命名数据结构（映射表、枚举、数据类）代替。
- 不新建不必要的文件或抽象层：能复用现有结构就不新增。
- 用命名常量代替魔法数字（0、1、-1 等公认语义值除外）。

## 冲突处理
- 当用户要求与全局约定矛盾时，先告知用户，得到明确许可后再执行。
- 当现有代码与全局约定矛盾时，新增或修改的代码遵循全局约定，历史遗留代码不修改。
- 发现历史遗留死代码、风格不一致等问题时，只提示用户，不主动修改。

## 代码维护
- 只删除本次改动产生的死代码。
- 历史遗留死代码不允许删除。
